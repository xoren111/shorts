Privacy Policy — AdmTools (OAuth app “ai”)

Last updated: 24 October 2026

Who uses the app

AdmTools is a private tool used only by the owner of the YouTube channel ATLAS APE. It is not distributed to the public.

What data it accesses

With the owner's consent, the app uses the YouTube API Services with read-only scopes to access the owner's own channel information (channel name, public statistics, list of videos) and YouTube Analytics reports for that channel (for example views, watch time, average view percentage and audience retention).

How the data is used and stored

  • The data is used only to analyse the performance of the owner's own videos.
  • The data and the OAuth refresh token are stored locally on the owner's computer. They are not sold, shared with or transferred to third parties, and are not used for advertising.
  • Data is kept only as long as needed for this analysis and can be deleted by the owner at any time.

Revoking access

Access can be revoked at any time in the Google Account security settings: myaccount.google.com/permissions.

YouTube and Google policies

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. See also the Google Privacy Policy. AdmTools' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
