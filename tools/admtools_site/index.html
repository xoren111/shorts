AdmTools

AdmTools (Google OAuth app name: ai) is a private, single-user helper that the owner of the YouTube channel ATLAS APE runs on his own computer.

It reads the owner's own channel statistics and YouTube Analytics reports (views, watch time, audience retention) with read-only access, so he can compare how his videos perform. It cannot upload, edit or delete anything, and it is not offered to other users.

APIs used: YouTube Data API v3 and YouTube Analytics API (YouTube API Services), scopes youtube.readonly and yt-analytics.readonly.
