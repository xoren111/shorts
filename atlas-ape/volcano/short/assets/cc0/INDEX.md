# CC0 3D asset index — volcano Short (Etna pilot, later Iceland)

Downloaded 2026-10-18 from the official sites only (kenney.nl, quaternius.com → its linked Google-Drive folders, polyhaven.com/dl.polyhaven.org). Nothing from the downloads was executed; `.blend` files were not downloaded; archive cruft (.url, .html, DAE/STL, isometric sprites) removed. Everything here is **CC0 1.0** (public domain) — credit optional (snippet below).

**Conventions.** Paths are relative to `assets/cc0/`. *Size* = bounding box W×D×H in Blender units after a default Blender 5.2 import (Z-up; glTF/FBX unit conversion applied), measured headless, so it is exact for that import. *Tris* = triangles. Kenney GLBs reference `Textures/colormap.png` next to them — keep the `GLB format/` folder intact (Nature Kit has no textures, only materials). Kenney also ships the same model as `Models/OBJ format/<name>.obj` and `Models/FBX format/<name>.fbx`. Quaternius = FBX + OBJ/MTL only (no glTF; Blender imports both; material colours, no textures). Per-model previews: Kenney `Previews/<name>.png` (64 px; Nature Kit: `Side/`), pack overview `Preview.png`. Modular kit pieces are listed as one *family* line with the size range.

**Colour note (Kenney City kits, Castle, Fantasy Town).** Models are UV-mapped to one palette texture `Textures/colormap.png`. Alternative palettes sit in `Models/Textures/variation-*.png`; for City Kit Suburban `variation-b.png` = terracotta roofs + brick walls (best for Sicily), `variation-a` = blue roofs, `variation-c` = grey. Swap the image in the material (or copy over colormap.png in a copy of the folder).

## Quick picks for the Etna pilot

- **Town houses (Sicilian):** `kenney-city-kit-commercial` building-a…e (white, flat roofs) + `kenney-city-kit-suburban` building-type-p/q (flat roof) and others with `variation-b.png` (terracotta); Quaternius `Building2_*`/`Building4` for a baroque piazza; Quaternius `House_3/House_4` (stone, flat roof) for village edges.
- **Church / bell tower:** `quaternius-medieval-village/Buildings/FBX/Bell_Tower.fbx` (+ `Props/FBX/Bell.fbx`), or stack Kenney castle `tower-square-*` (recipe in its family line) next to a nave built from fantasy-town `wall-*` + `roof-high-*`. No complete church model exists in these CC0 sources.
- **Trees:** Kenney nature `tree_plateau` (stone pine), fantasy-town `tree-high-round` (cypress-like), `tree_pine*`, palms; Quaternius `PineTree_*`, `CommonTree_*`, `CommonTree_Dead_*` (burnt). **Rocks:** Kenney nature `stone_*` (grey; `rock_*` = sandy-orange twins), pirate/castle `rocks-*`, Quaternius `Rock_*`; Poly Haven `moon_rock_*` = dark basalt look.
- **Bulldozer:** `kenney-car-kit/Models/GLB format/tractor-shovel.glb` (dozer-blade tractor) — the only earth-moving machine found; no CC0 tracked excavator/bulldozer found on kenney.nl (site search), quaternius.com (pack list) or polyhaven.com (API). Fire engine/police/ambulance for evacuation beats.
- **Iceland boat:** `kenney-watercraft-kit/…/boat-fishing-small.glb`, `boat-tug-*`; Quaternius `BoatWSail.fbx`; docks from pirate `structure-platform-dock`.
