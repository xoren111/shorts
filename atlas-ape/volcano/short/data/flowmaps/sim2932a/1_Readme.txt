The main component of this digital release is a geologic map database prepared using ArcGIS.FILES AND FOLDERS1_Readme.txt  Overview of the data folder - this filesim2932a_basemap.txt                      FGDC metadata text file describing the topographic base map.sim2932a_GeoDatabase.zip                      sim2932a_ArcMap.mxd:  ArcMap document containing cartography and                        symbology for the geologic map database.                      sim2932a_geodatabase.gdb                        An ESRI geodatabase file for the geologic map of Geologic Map of the Northeast Flank of Mauna Loa Volcano, Island of Hawai'i.                       wpgcmykg.style                        An ESRI style file used for displaying the CMYK geologic map unit polygon colors.sim2932a_geodatabase_overview.txt                      FGDC metadata text file describing the geologic map database.PRINTED COPY AVAILABLETo order this and other USGS information products, visit http://store.usgs.govSUGGESTED CITATIONTrusdell, F.A., and Lockwood, J.P., 2017, Geologic map of the northeast flank of Mauna Loa volcano, Island of Hawai'i, Hawaii: Scientific Investigations Map 2932ÐA, pamphlet 25 p., 2 sheets, scale 1:50,000, https://doi.org/10.3133/sim2932A.ISBN  978-1-4113-3813-5DISCLAIMERSAll trademarks and trade names are the property of their respective owners.
