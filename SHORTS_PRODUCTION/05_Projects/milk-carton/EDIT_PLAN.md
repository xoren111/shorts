# EDIT_PLAN — milk-carton
Визуальная идея: Одна и та же нарисованная картонка с её лицом — сквозной предмет, который код передаёт из сцены в сцену (холодильник → лазер кассы → ножницы → кейс для кукол → холодильник соседки → линия печати → стена пакетов → снова холодильник кадра 0); взрослых видно только по рукам (часы отчима, браслет матери, клетчатый рукав отца), лиц нет никогда.
Кадр 0: рисунок, человек: девочка лет семи крупно (лицо, у A1 был человек в полный рост — H14/Т7) у открытого холодильника уже в движении с 0.0 s — поворачивает голову к въезжающему пакету и подаётся вперёд, глаза расширяются; мужская рука (только манжета и часы) подносит к её щеке пакет молока, на нём её зеркальная копия под огромным MISSING; на 0.45 s глаза на фото встают вровень с её глазами — удар баса без остановки кадра; на 1.0 s она тычет пальцем себе в щёку
