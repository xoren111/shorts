1. **Агенты при загрузке:** размер > 0; ffprobe для аудио/видео (кодек, длительность, разрешение, альфа, громкость ebur128 у музыки); `file(1)`; `unzip -l` для zip; fontTools/fc-scan для шрифтов; SVG — на `<script>`, on*-обработчики, внешние ссылки и встроенный растр; LUT — прогон через ffmpeg `lut3d`; Lottie — рендер в lottie-web. Для Commons сверен SHA-1 с API, для Poly Haven — MD5 с API. Лицензия Mixkit (Free, а не Restricted) проверена на странице каждого клипа.
