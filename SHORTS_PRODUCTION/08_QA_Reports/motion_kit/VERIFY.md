## Замечания

**З1 (средняя) — кадр 0 MotionDemo: слова slam наезжают друг на друга.**
- Кадр 0: «THIS» в импакт-кадре (чёрный текст на белой вспышке), сверху падает «IS» в 2.3×, буква S скрыта. В кадре 1 «IS» ещё
  перекрывает «THIS»; с кадра 2 всё читается. Без клипа (рамка-заглушка) картина та же.
- Причина: пресет `slam` не разводит слова, которые стоят ближе ~0.1 s (`W(0)` = 0.00, `W(1)` = 0.07). Импакт первого слова
  попадает ровно в кадр 0.
- Кадр 0 — первый кадр в ленте и шов петли, поэтому мусор в нём дороже, чем в любом другом месте.
- Предложение:
  - в slam первое слово в кадре 0 сразу приземлено, без импакт-кадра;
  - слова ближе 0.12 s объединять или сдвигать;
  - `kinetic_check` выдаёт предупреждение на slam в 0–0.1 s.

**З2 (средняя, шлюз) — карта в кадре 0 с `live: true` проходит.** N3b / N3c дают exit 0 с предупреждением. В стандарте H1 и V4 сказано
прямо: кадр 0 — живое существо, не карта. R4 разрешает карту в хуке только с живым действием на ней, а `live` в коде отменяет и запрет
на кадр 0. Задание («карта первым планом в 0 s → ошибка») выполнено только для случая без `live`. Предложение: карта в кадре 0
(бит с t0 = 0) — ошибка всегда; `live` разрешает карту в 0–3 s, но не в кадре 0. Это решение владельца.

**З3 (низкая) — подпись трекинга в MotionDemo выходит за safe zone слева.**

  Планировщик даёт x центра 418, то есть левый край 48 до масштаба.
- Предложение: в демо вынести подпись из масштабируемого слоя. В README `Tracked` написать, что внешний transform ломает safe zone.
