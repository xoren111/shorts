## Pixabay API (с 2026-10-24, ключ владельца)

- **Доступ:** официальный API `https://pixabay.com/api/` (фото) и `https://pixabay.com/api/videos/` (видео). Ключ лежит в
  `SHORTS_PRODUCTION/.env.assets` (права 0600), в чат и логи не печатается. Музыки и звуковых эффектов в API **нет** — они по-прежнему manual.
- **Инструмент:** `~/shorts/tools/pixabay.py search|get images|videos …` — кэш запросов 24 ч (`02_Research/pixabay_cache`), пауза между запросами,
  каждая загрузка пишется в `02_Research/download_logs/pixabay.json` (автор, страница, лицензия, sha256).
- **Правила API (docs, проверено 24.10):** до 100 запросов за 60 с на ключ; запросы кэшировать 24 ч; запросы — по реальной задаче человека,
  не автоматический поток; **систематические массовые загрузки запрещены**; картинки скачивать к себе (постоянный хотлинк запрещён), видео можно
  встраивать; при показе результатов поиска указывать, что они с Pixabay.
- **Что отдаёт без «full API access»:** фото до 1280 px (`largeImageURL`); оригиналы и 1920 px — только после одобрения full access в аккаунте.
  Видео — large/medium/small/tiny (есть вертикальные 1080×1920 и 2160×3840).
- **Лицензия контента:** та же Pixabay Content License (см. выше): коммерческое использование да, атрибуция не нужна, нельзя распространять отдельно,
  нельзя изображать узнаваемых людей в порочащем контексте, товарные знаки — осторожно.
- **Проверено 24.10:** поиск фото и видео, загрузка фото 1280 px и видео 1280×588 через `pixabay.py` — HTTP 200, ffprobe ОК.
