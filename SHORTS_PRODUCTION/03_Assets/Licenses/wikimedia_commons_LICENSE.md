# Wikimedia Commons — лицензия у каждого файла своя

- **Источник:** https://commons.wikimedia.org (аудио скачивается напрямую с upload.wikimedia.org, без логина)
- **Правило проекта:** берём только файлы с Public Domain, CC0 1.0, CC BY (3.0/4.0) или CC BY-SA (3.0/4.0). NC/ND и «fair use» — никогда.
- **Где проверено:** у каждого файла — поле `LicenseShortName` + `Artist` из Commons API (`prop=imageinfo&iiprop=extmetadata`) и страница файла `File:…`. Конкретная лицензия, автор и ссылка записаны по каждому файлу в `02_Research/download_logs/sfx.json`.
- **Коммерческое использование / YouTube:** PD, CC0, CC BY, CC BY-SA — разрешено.
- **Атрибуция:**
  - PD / CC0 — не требуется (пишем в CREDITS.md для порядка);
  - CC BY / CC BY-SA — обязательно: автор, название файла, ссылка на страницу файла, название лицензии со ссылкой, отметка «изменено» при обрезке/обработке. Готовый текст — в поле `attribution_text` лога.
- **CC BY-SA:** изменённый САМ звук (как отдельный файл) остаётся под CC BY-SA; видео, в котором он просто используется, по общей практике CC — не «адаптация» звука, но кредит нужен. Если этого хотим избегать — берём PD/CC0 версии.
- **Content ID:** чужие PD/CC-звуки не регистрировать на себя.
- **Зеркала Freesound на Commons:** файлы вида «<id> <автор> <название>.wav» — это CC0-оригиналы Freesound, загруженные на Commons; лицензия проверяется так же по Commons.
