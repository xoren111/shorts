# Noto Emoji (статичные SVG) — лицензия

- **Источник:** https://github.com/googlefonts/noto-emoji — каталог `2D/svg/` (ветка `main`), файлы `emoji_u<codepoint>.svg`.
- **Лицензия:** README репозитория: шрифты — SIL OFL 1.1, а инструменты и большинство изображений — Apache License 2.0. Корневой файл LICENSE с 2024-07-29 содержит текст OFL 1.1 (коммит «Update LICENSE to OFL»). Обе лицензии — пермиссивные, обе разрешают коммерческое использование.
  Копии сохранены: `03_Assets/Graphics/emoji/LICENSE_noto-emoji_repo_OFL.txt` и `LICENSE_Apache-2.0.txt`.
- **Проверено:** 2026-10-24.
- Коммерческое использование: **да**. Атрибуция в видео: **не требуется** (по желанию можно указать «Noto Emoji by Google»).
- Ограничения: при распространении самих файлов приложить лицензию. Флаги (third_party/region-flags) не скачивались.
- Почему Noto, а не Twemoji или OpenMoji: у Twemoji графика под CC BY 4.0 (атрибуция обязательна), у OpenMoji — CC BY-SA 4.0 (атрибуция + share-alike). У Noto ограничений меньше всего.
