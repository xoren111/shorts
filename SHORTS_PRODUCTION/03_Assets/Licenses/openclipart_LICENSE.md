# Openclipart — лицензия (рисованные стрелки и маркеры)

- **Источник:** https://openclipart.org — страницы `https://openclipart.org/detail/<id>`, SVG по официальной кнопке «Download SVG» (`/download/<id>/...svg`), без логина.
- **Лицензия:** **CC0 1.0 Universal (Public Domain Dedication)** — https://creativecommons.org/publicdomain/zero/1.0/ . По правилам сайта (https://openclipart.org/share) каждый загруженный рисунок выпускается под CC0. В JSON-LD каждой скачанной страницы поле `license` тоже указывает CC0 1.0.
- **Проверено:** 2026-10-24. У всех 12 выбранных работ нет тега `pd_issue` (так сайт помечает рисунки с сомнительным происхождением). SVG с встроенным растром отбрасывались (id 257719).
- Коммерческое использование: **да**, без ограничений. Атрибуция: **не требуется** (по желанию — автор указан в логе `02_Research/download_logs/graphics.json`).
- Ограничения: CC0 не передаёт права на товарные знаки и права на изображение людей. Выбранные файлы — абстрактные стрелки и штрихи, к ним это не относится.
