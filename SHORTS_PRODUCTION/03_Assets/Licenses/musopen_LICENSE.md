# Musopen — записи в общественном достоянии (через Wikimedia Commons)

- **Что это:** записи некоммерческой организации Musopen (в т. ч. Musopen Kickstarter Project, Czech National Symphony Orchestra как «Musopen Symphony»), выпущенные в Public Domain. Скачаны с официальных копий на Wikimedia Commons (upload.wikimedia.org), т. к. musopen.org для скриптов отдаёт 403 и требует аккаунт/лимиты.
- **Страницы файлов:**
  - https://commons.wikimedia.org/wiki/File:Grieg_-_Peer_Gynt_Suite_No._1,_Op._46_-_IV._In_the_Hall_of_the_Mountain_King_(Musopen_Symphony).flac — запись `PD-author (Musopen)`, композиция `PD-old-auto-expired` (Григ † 1907)
  - https://commons.wikimedia.org/wiki/File:Erik_Satie_-_gymnopedies_-_la_1_ere._lent_et_douloureux.ogg — запись `PD-author (Robin Alciatore)`, источник musopen.com, композиция PD (Сати † 1925)
- **Лицензия:** Public Domain — ограничений нет; коммерческое использование и монетизация разрешены. Сайт Musopen: https://musopen.org
- **Атрибуция:** юридически не нужна. Musopen **из вежливости просит** не продавать сами записи и упоминать Musopen в коммерческих/производных работах — пишем в описании/CREDITS: «Music: <piece> — <composer>, performed by <performer> (Musopen, public domain)».
- **Content ID:** запись PD, сам Musopen её не регистрирует. Но у классики известны **ложные совпадения** с записями лейблов (Content ID путает разные исполнения одного произведения). «Mountain King» и «Gymnopédie» — одни из самых записываемых пьес, поэтому оценка риска: **средний** (повышена 24.10 с «низкий–средний»); только в Shorts ≤ 60 s; при claim — dispute «recording is public domain» со ссылкой на страницу Commons.
- **Проверка целостности:** SHA-1 скачанных файлов совпадает с SHA-1 из Commons API.
- **Дата проверки:** 2026-10-24
