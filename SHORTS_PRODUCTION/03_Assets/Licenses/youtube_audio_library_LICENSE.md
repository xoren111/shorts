# YouTube Audio Library — лицензия YouTube Audio Library / Creative Commons

- **Источник:** YouTube Studio → «Audio Library» (https://studio.youtube.com → Аудиотека). Нужен вход в аккаунт канала → для этой системы статус **manual** (скачивает владелец сам).
- **Справка:** https://support.google.com/youtube/answer/3376882
- **Типы лицензий:**
  - стандартная лицензия YouTube Audio Library — **атрибуция не нужна** (фильтр «Attribution not required»);
  - Creative Commons — **кредит обязателен в описании**; текст берётся в Studio кликом по значку CC в колонке «License type».
- **Content ID:** по справке YouTube музыка и звуки из Audio Library **не получают Content ID claim**; монетизация в YPP разрешена. Это источник с самым низким риском — и единственный, который YouTube прямо рекомендует для Shorts длиннее 1 минуты (https://support.google.com/youtube/answer/15424877).
- **Вне YouTube:** справка этого не описывает → использовать только в роликах для YouTube; для других платформ — уточнять отдельно.
