# Graphics — иконки, эмодзи, рисованные стрелки и маркеры

Превью всех файлов: `_preview_graphics.png`. Полный машинный лог (sha256, автор, URL): `../../02_Research/download_logs/graphics.json`.
Все SVG проверены: нет `<script>`, обработчиков событий, внешних ссылок и встроенного растра.

| Папка | Что | Лицензия | Атрибуция в видео |
|---|---|---|---|
| `icons/lucide/svg/` | 95 линейных иконок (стрелки, карта, пин, огонь, череп, деньги, время, корабли…) из Lucide 1.61.0 | ISC (+ MIT для иконок из Feather) | не нужна |
| `icons/lucide/_archive/lucide-icons-1.61.0.zip` | полный официальный набор (1903 SVG + JSON с тегами) — если нужна иконка вне подборки | ISC | не нужна |
| `icons/tabler/filled/` | 46 залитых иконок Tabler v3.49.0 (на мелких размерах читаются лучше линейных) | MIT | не нужна |
| `icons/tabler/outline/` | 32 линейных, в основном изогнутые и петляющие стрелки, scribble, радар, мечи | MIT | не нужна |
| `emoji/noto_svg/` | 54 эмодзи Noto (огонь, 💥, ❓, ✅/❌, 💸, 📍, 🗺, 🏆, 👑, ⚔️, 🚢, 🌋, лица-реакции, руки-указатели) | Apache 2.0 / OFL 1.1 | не нужна |
| `arrows_markers/` | 12 рисованных SVG: 5 стрелок, набор из 12 «обвести кружком», подчёркивание, ✓/✗, гранжевый мазок, красный мазок-круг, зачёркивание, клякса-взрыв | CC0 (Openclipart) | не нужна |

Использование в Remotion: положить нужный файл в `public/` проекта → `<Img src={staticFile('icons/flame.svg')}/>`. Линейные иконки
используют `stroke="currentColor"`, поэтому для перекраски SVG лучше встроить inline. Рисованное появление стрелки или круга:
анимировать `strokeDashoffset` (так сделано в `MarkerRing`, `~/shorts/atlas-ape/football-222/short/src/ui/vox.tsx`).
Тот же подход подходит для кодовых аннотаций rough-notation / roughjs (MIT, npm), если понадобится больше «от руки».
