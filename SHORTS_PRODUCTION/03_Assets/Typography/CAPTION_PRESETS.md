# CAPTION_PRESETS — стили субтитров и текста для Shorts (1080×1920)

Основа — рабочий компонент `~/shorts/atlas-ape/pig-war/short3/src/ui/Subtitles.tsx` (+ `gfx.tsx`: `GOLD #FFC83A`, `GOLD2 #FF9A1F`,
`TEAL #22E6D8`, `INK #120818`, хелпер `stroke(w)` = `WebkitTextStroke` + `paintOrder: 'stroke fill'`) и правила владельца из
обратной связи по Atlas Ape (раунды 1–9). Шрифты — из `03_Assets/Fonts/` (OFL/Apache, см. `Licenses/google-fonts_LICENSE.md`).

## Общие правила (для всех пресетов)

| Правило | Значение |
|---|---|
| Когда виден | **только пока звучит фраза**: от `word.start − 0.03 s` до `lastWord.end + 0.15 s`; в паузах экран без субтитров |
| Группа | 1–3 слова, ≤ 14 символов, разрыв на пунктуации или паузе > 0.35 s (как в `GROUPS` в Subtitles.tsx) |
| Ничего дважды | если фраза показана крупным текстом/числом/стикером, её субтитр **скрываем** (`hidden(t)`); никаких чипов, повторяющих голос |
| Цвета текста | белый + **оранжевый** `#FF7A1F` (с 24.10, палитра «A · Экспедиция»; до этого белый + золото). Жёлтый текст с фиолетовыми акцентами владелец отклонил. Фиолетовый допустим только как UI-акцент (тосты, бейджи) |
| Highlight | ≤ 1 оранжевого слова на группу (в коде `gold_words`): число, имя, ключевое существительное. Teal — только «водные» слова (море, река, наводнение) |
| Наклон | **без наклона** (правило раунда 9). Rotate −6° из pop-анимации в Subtitles.tsx нужно убрать. Анимации: rise-out-of-mask, bar-wipe, pop (scale) |
| Читаемость | обводка INK ≥ 0.15 × кегля + тень `0 4px 0 INK`. На ярком небе/снегу — тёмная подложка (scrim) |
| Наложения | субтитр не пересекается с другим текстом (credit-пилюли, подписи, UI телефона/Follow) — одна текстовая зона за раз |
| Прозрачность | 0.92 |

### Safe zone (1080×1920, интерфейс YouTube Shorts)
```
y    0–220   верх: поиск, меню          → без текста
y  220–1560  рабочая зона текста
y 1560–1920  низ: название, канал, описание, прогресс → без текста (в Subtitles.tsx: «never in the bottom 15 %», т.е. y < 1632)
x  960–1080  справа колонка кнопок (лайк/коммент/шер) на y ≈ 1000–1650 → у длинных строк правый край ≤ 960
```
- Субтитры: центр строки **y ≈ 1300** (≈ 68 % высоты; владелец просил «ниже в кадре»), блок `left 120, width 840`, по центру.
- Крупный хук/число: **y ≈ 700–900**, поверх пустого места кадра, не поверх главного объекта.
- Подпись (label) и credit-пилюля: верхняя треть (y 260–520) или у объекта, но **не** в полосе субтитров y 1180–1420.

## Пресет A — «Atlas Standard» (по умолчанию, каждое слово)
Текущий стиль канала, уже проверенный в Pig War / 222–0 / AI farm girl.

| Параметр | Значение |
|---|---|
| Шрифт | **Montserrat 900** (`Fonts/Montserrat/Montserrat-VariableFont_wght.ttf`, wght 100–900). Есть кириллица и ÄÖÜß, поэтому годится для RU/DE-версий |
| Кегль при 1080 w | **54 px**, `lineHeight 1.1`, UPPERCASE, `letterSpacing 0`, `columnGap 26` |
| Заливка | `#FFFFFF`; ключевое слово `GOLD` = `#FF7A1F` (оранжевый с 24.10); вода `TEAL #22E6D8` |
| Обводка | `stroke(9)`, цвет INK `#120818` |
| Тень | `0 4px 0 #120818, 0 0 16px rgba(0,0,0,.8), 0 0 34px rgba(0,0,0,.5)` |
| Анимация | каждое слово появляется в момент произнесения: `scale 0.6 → 1` за 0.22 s (pop), активное слово ×1.03; **без rotate** |
| Позиция | центр y ≈ 1300, `left 120 / width 840` |

## Пресет B — «Punch» (хук в первые 3 с, крупные числа, 1 слово)
Для кадра-события: «35 000», «1859», «$1 000 000», «NOBODY». Пока он на экране, субтитр этой фразы скрыт.

| Параметр | Значение |
|---|---|
| Шрифт | **Alfa Slab One 400** (`HEAD`, с 24.10, палитра «A · Экспедиция»; раньше Anton 400; только латиница + ÄÖÜß). Для кириллицы — **Oswald 700** или **Russo One** |
| Кегль | **100–130 px** для Alfa Slab One — он шире Anton (число до 6 символов — 130, слово — 100), `lineHeight 0.95`, UPPERCASE |
| Заливка | оранжевый градиент `goldFill` из gfx.tsx (`#FFC48F → #FF7A1F → #E2560C`, с 24.10) или белый |
| Обводка/тень | `stroke(12)` INK + `drop-shadow(0 9px 0 #120818) drop-shadow(0 0 34px rgba(255,140,30,.55))`. На ярком фоне — scrim `rgba(18,8,24,.55)`, blur 40 px за текстом |
| Анимация | pop `scale 0.6 → 1.08 → 1` за 0.3 s или rise-out-of-mask снизу; держать 0.8–1.5 с; **без вращающихся счётчиков** (владелец: «~96 m» на середине счёта выглядит плохо) |
| Позиция | центр y ≈ 760–880, ширина ≤ 900 |
| Частота | ≤ 1 раза на 8–10 с, иначе обесценивается |

## Пресет C — «Doc Label / Annotation» (Vox-коллаж, немецкие исторические ролики, подписи у стрелок)
Одна спокойная горизонтальная подпись, только если она добавляет информацию: имя, дату, место, которых нет в голосе.

| Вариант | Шрифт и кегль | Оформление |
|---|---|---|
| C1 Label | **Inter 800** (opsz 32) или **Rubik 700**, **40–46 px**, обычный регистр | белый текст на пилюле `rgba(18,8,24,.72)`, radius 14, padding 10×18, тонкая обводка 2 px `rgba(255,255,255,.15)`; появление bar-wipe слева 0.25 s |
| C2 Hand note | **Permanent Marker 400** (латиница) или **Caveat 700** (кириллица), **48–56 px** | белый или золотой, `stroke(6)` INK. Ставится рядом со стрелкой/кругом из `Graphics/arrows_markers/` (CC0) или с кодовым `MarkerRing` из `football-222/short/src/ui/vox.tsx` |
| C3 Meme/comic | **Bangers 400**, 64–80 px (только латиница) | белый + `stroke(10)` INK, только поверх мем-вставки, не как отдельный план (раунд 9) |

## Подключение шрифтов в Remotion
- Сейчас в `short3/src/fonts.ts` шрифты грузятся через `@remotion/google-fonts` с `subsets: ['latin']`. Для русского или немецкого текста нужно добавить `'cyrillic'` / `'latin-ext'`, иначе Ё/Й/ß отрисуются запасным шрифтом.
- Локальные файлы из `03_Assets/Fonts/` (работает офлайн, версия зафиксирована): скопировать TTF в `public/fonts/` проекта и подключить так:
  ```ts
  import {loadFont} from '@remotion/fonts';          // npx remotion add @remotion/fonts
  import {staticFile} from 'remotion';
  loadFont({family: 'Montserrat', url: staticFile('fonts/Montserrat-VariableFont_wght.ttf'), weight: '100 900'});
  ```
- Variable-шрифты (Montserrat, Inter, Oswald, Rubik, Caveat) Chrome и Remotion понимают сразу. Blender берёт только начертание по умолчанию: для 3D-текста в Blender лучше статические Anton / Bebas Neue / Russo One.
- ffmpeg собран без `drawtext`/`libass`, поэтому текст рисуем только в Remotion/Blender, не в ffmpeg.
